## MongoDB Enterprise Edition Setup and Compass Installation

1. Visit the official MongoDB website and sign up for an account.
2. Create a new cluster.
3. Once the cluster is ready, copy the provided connection string.
4. Download and install - MongoDB Compass.
5. In Compass, select "Add a new connection" and paste the connection string.
6. Create a database and add collections to begin working with your data.

Note: The connection string is essential for interacting with your cluster programmatically.

- The mongodb package can be used for practice and learning purposes. For production applications, it is strongly recommended to use the Mongoose library, which provides schema validation, middleware, and a more structured approach to working with mongo database.
